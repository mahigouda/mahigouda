## Mahesh Gouda, PhD

**Computational biologist · Senior bioinformatics postdoc**, University Hospital Bonn

Multi-omics and clinical data analysis for biological and translational research, spanning stem-cell and developmental biology, cancer, respiratory disease and psychiatric genomics (11+ years).

### Focus areas

- **Single-cell and bulk transcriptomics:** scRNA-seq and bulk RNA-seq, integration, clustering, trajectory analysis, cell-type annotation
- **Functional genomics:** pooled CRISPR/Cas9 screens (MAGeCK), CRISPR single-cell sequencing, pathway and gene-set enrichment
- **Multi-omics integration:** transcriptomics, proteomics (LC-MS/MS), lipidomics, metabolomics, genetics
- **Clinical data and survival modelling:** prognostic signatures, penalised Cox regression, risk stratification, external validation
- **Reproducible workflows:** Snakemake, Nextflow, Docker, HPC (SLURM), Git

### Tools

`R` · `Python` · `Bash` · Seurat · Scanpy · Monocle · DESeq2 · limma/edgeR · clusterProfiler · MAGeCK · scikit-learn · scikit-survival · lifelines · ggplot2 · Snakemake · Nextflow · Docker
